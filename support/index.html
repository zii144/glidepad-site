Support

Help for the Glidepad app and the Glidepad agent.

Need help or found a problem? Open a support request. Tell us your phone model, your computer (Mac, Windows or Linux, and its version), the Glidepad version (Settings → About), and what happened. Please don’t include passwords or other private information: requests are public.

Setting up

  1. Install the Glidepad agent on your computer. It runs on macOS 11 or later, Windows 10 or later (64-bit), and 64-bit Debian or Ubuntu. See the download page.
  2. Install the Glidepad app on your phone and keep it on the same Wi-Fi network as the computer.
  3. Pair them once. Click the Glidepad icon next to the clock on your computer, choose Pair a phone…, then tap Pair a Computer in the app and scan the code.

On a Mac, also open System Settings → Privacy & Security → Accessibility and switch Glidepad on. Without it, macOS ignores the pointer and keys.

Common problems

The phone can’t find the computer

Check that both are on the same Wi-Fi and that the Glidepad icon is showing on the computer. Guest, hotel and office networks often stop devices from seeing each other. On iPhone and iPad, check Settings → Privacy & Security → Local Network and make sure Glidepad is on. On Windows, set your home Wi-Fi to Private.

The pointer doesn’t move on a Mac

Open System Settings → Privacy & Security → Accessibility, switch Glidepad off and on again, then quit Glidepad from its icon and open it again.

It stopped responding

Click the Glidepad icon and choose Quit Glidepad, then open it again from Applications (Mac) or the Start menu (Windows). Your phone reconnects by itself.

Typing doesn’t reach some windows on Windows

Windows doesn’t let ordinary programs send input to windows running as administrator. Run the agent as administrator if you need to control those windows.

I want to unpair a phone or a computer

In the app, tap the … button next to a computer and choose Forget This Computer. On the computer, run glidepad-agent forget <name>.

Privacy and security

Glidepad has no account and no server. Your phone and computer talk directly over your own network, and every message is end-to-end encrypted. Read the full privacy policy.

If you think you have found a security problem, please don’t post the details publicly. Open a support request that says only “security issue”, and we will arrange a private way to talk.
